# VISUTRA AdSense review checklist

This version adds a content/resource layer to address the "Low value content" issue shown in AdSense.

## Before requesting another review
1. Push the complete site to GitHub Pages and confirm every new URL opens with HTTPS.
2. In Google Search Console, inspect and request indexing for the new public pages.
3. Submit `https://visutra.in/sitemap.xml`.
4. Test the mobile layout and all internal links.
5. Confirm `ads.txt` still loads at `https://visutra.in/ads.txt`.
6. Confirm the AdSense code is present on the pages you want monetized.
7. Remove any placeholder, duplicate, unfinished or misleading content before review.
8. Do not publish bulk AI-generated articles just to increase page count. Add original measurements, product-specific information, photos and practical observations.
9. Wait until the important public content pages are indexed/accessible, then request another AdSense review.
